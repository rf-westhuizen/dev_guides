## When to Consult These Sources

- **Starting a new feature:** Flutter Architecture Guide + Riverpod docs
- **Writing models:** Freezed docs + Effective Dart: Design
- **Database work:** Drift docs (DAOs, migrations, modular codegen)
- **Platform integration:** Pigeon docs + Flutter Platform Channels guide
- **Testing:** VGV Testing Overview + Mocktail docs + Riverpod Testing
- **Code review:** Effective Dart (all sections) + VGV Philosophy
- **Design patterns:** Refactoring Guru for Strategy, Factory, Observer
