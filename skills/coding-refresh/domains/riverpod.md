## Sources

- https://pub.dev/api/packages/flutter_riverpod - Use for: latest stable `flutter_riverpod` version, published date and Dart SDK floor.
- https://pub.dev/api/packages/riverpod_annotation - Use for: latest stable `riverpod_annotation` version.
- https://pub.dev/api/packages/riverpod_generator - Use for: latest stable `riverpod_generator` version.
- https://pub.dev/api/packages/riverpod_lint - Use for: latest stable `riverpod_lint` version.
- https://pub.dev/packages/flutter_riverpod/changelog - Use for: API changes per version.
- https://pub.dev/packages/riverpod_generator/changelog - Use for: code generation changes per version.
- https://pub.dev/packages/riverpod_lint/changelog - Use for: how `riverpod_lint` is installed and run in each version.
- https://riverpod.dev/docs/whats_new - Use for: what changed in Riverpod 3.
- https://riverpod.dev/docs/3.0_migration - Use for: 2.x APIs that were renamed or removed in 3.0.
- https://riverpod.dev/docs/root/do_dont - Use for: the author's own do and don't list.
- https://riverpod.dev/sitemap.xml - Use for: finding the new address of a moved docs page.
